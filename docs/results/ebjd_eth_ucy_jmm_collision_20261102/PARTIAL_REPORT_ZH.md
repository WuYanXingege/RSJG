# EBJD 统一方案 JMM 碰撞指标阶段报告

状态：`PARTIAL_4_OF_5`。ETH、HOTEL、ZARA1、ZARA2 已完成；UNIV 正在按冻结协议补评测。因此本报告不给出“完整五折宏平均”，下表四折宏平均仅用于当前进度判断。

## 口径

采用 JMM 官方实现语义：行人半径 `0.1 m`、中心距离阈值 `0.2 m`，按同步相邻未来轨迹段检测帧间碰撞。CRJADE 使用整场景 JADE 最优的共同 world；CRmean 平均全部 20 个共同 world。所有数值均为百分数，越低越好；标准差是同一训练 checkpoint 的五个推理 seed（2035–2039）样本标准差，不是五个训练 seed。

## 阶段判断

- ETH：H 两项均值优于 GDTS，均为 5/5 seed 改善。
- HOTEL：G 两项 CR 均退化，但 H 将两项均值恢复到 GDTS 以下；这说明 HOTEL 的配对确实减少碰撞，而不是 G 的条件桥天然更安全。其方向一致性为 CRJADE 4/5、CRmean 3/5。
- ZARA1：H 相对 GDTS 和 G 的两项指标均显著降低，且相对 GDTS 为 5/5 seed 改善。
- ZARA2：H 相对 GDTS 和 G 的两项指标均为 5/5 seed 改善。
- 已完成四折中，联合位移指标改善总体伴随 CR 改善；HOTEL 的 minADE 退化并未伴随 H 的碰撞率退化。

当前证据支持学习配对 H 降低碰撞，但在 UNIV 完成前，不能宣称完整五折均改善，也不能给出五折全体/N≥2宏平均。最终报告将补充 UNIV、GT CR、N=1/N≥2、完整逐场景分子分母、科学图和 GPU/CPU 成本。
