# JMM 碰撞率口径

本评测跟随 `joint-metrics-matter` 官方仓库提交
`894182b5ea7dac3c93bbe0bcc18c156c932398b7` 的
`evaluation/metrics.py`。模型半径取 `b=0.1 m`，两人中心距离阈值为
`2b=0.2 m`。

## 同步运动碰撞

对同一场景、同一 world 的任意两名有效行人，先检查第一帧未来位置的
距离，再检查 11 个相邻未来时间区间。区间内把两人的相对位置作线性
插值，计算该相对运动线段到原点的最短距离。距离严格小于 `0.2 m` 才
记为碰撞。该定义不是普通二维路径段相交：空间轨迹相交但到达时间不同
不构成碰撞。官方实现不加入“最后观测点到第一预测点”的连接段。

一个人在一个 world 内无论与多少人、碰撞多少次，均只记一次。碰撞
双方分别记为碰撞行人；自身、padding 和其他 world 均不参与比较。
单人场景的两项 CR 均为 0，并按官方场景等权聚合规则保留在全体分母。

## CRJADE 与 CRmean

对每个场景，官方代码用欧氏位移距离在未来帧和有效行人上取均值，得到
每个共同 world 的场景误差；`argmin` 的首个索引是 JADE world。CRJADE
是该共同 world 中碰撞行人的比例。论文公式排版使用平方范数，但本报告
的“JMM 官方代码口径”使用公开实现的欧氏范数，未以论文排版替换代码。

CRmean 是全部 20 个 world × 全部有效行人的碰撞标记平均值；它不是
最低碰撞 world，也不是“场景是否至少发生一次碰撞”。数据集层面对场景
等权平均，而非把所有行人合并后微平均。

GT CR 对同一批真实未来使用完全相同的同步线段规则，不平滑、不强制为
0。报告同时给 0–1 原始比例和 0–100% 百分数；方法差值以百分点表示。

## 证据边界

2035–2039 是同一训练 checkpoint 的五个推理随机种子，不是五个独立
训练种子。新增 CR 只评估冻结输出，不参与 checkpoint 选择，也不对
world、候选或轨迹作碰撞后处理。
