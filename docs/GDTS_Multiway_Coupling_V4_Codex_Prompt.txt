============================================================
一、最终主线：从“参考行人对齐”升级为“图上的多路置换同步”
============================================================

最终主模型应被理解为：

    GDTS marginal generator
        ↓
    每个行人 K 条完整未来轨迹
        ↓
    synchronized sparse social graph
        ↓
    candidate-trajectory-pair-conditioned relation
        ↓
    candidate-trajectory-pair compatibility
        ↓
    graph-wide multiway permutation synchronization
        ↓
    Sinkhorn relaxed doubly-stochastic assignments
        ↓
    Hungarian hard permutation
        ↓
    joint future samples

关键思想：

原 GDTS 为每个 agent i 生成 K 条完整未来：

    Y_i = {Y_i^1, ..., Y_i^K}

其中：

    Y_i^a ∈ R^{T_pred × 2}

我们不修改这些轨迹坐标，而只学习每个行人的一个 permutation：

    π_i : {1,...,K} -> {1,...,K}

或者 permutation matrix：

    P_i ∈ {0,1}^{K×K}

满足：

    P_i 1 = 1
    P_i^T 1 = 1

最终 joint sample s 为：

    \tilde Y_i^s = Y_i^{π_i(s)}

因此对任何 agent i：

    { \tilde Y_i^s | s=1...K }
    =
    { Y_i^a | a=1...K }

所以在相同原始轨迹集合下：

    minADE_aligned(i) = minADE_raw(i)
    minFDE_aligned(i) = minFDE_raw(i)

这不是“靠较小学习率避免伤害边际”，而是由输出空间的双射约束严格保证。

============================================================
二、核心概率/优化解释：学习 marginals 之间的 coupling
============================================================

把 agent i 的 K 条离散样本看成经验边际分布：

    μ_i = (1/K) Σ_a δ_{Y_i^a}

我们不修改 μ_i，只学习多行人联合经验分布：

    γ = (1/K) Σ_s
        δ_(Y_1^{π_1(s)}, ..., Y_N^{π_N(s)})

这个 γ 的每个边际仍为 μ_i。

因此新模型从理论上可以描述为：

    fixed marginal future distributions
        +
    learned social dependence / coupling

而不是再学习一套新的 trajectory generator。

这条数学主线应贯穿代码注释、文档和后续论文：
- marginal quality 由 GDTS 负责；
- joint consistency 由 coupling module 负责；
- coupling 不创造新轨迹，只重新组织样本之间的联合对应关系。

============================================================
三、不要再把一个 reference agent 当作所有人的中心
============================================================

当前 Stage 3 的 reference-agent 方案可以保留为消融，但新主模型必须改成：

    graph-wide multiway permutation synchronization

对于一个 connected component C 中每个 agent i，都维护：

    P_i ∈ B_K

其中 B_K 是 Birkhoff polytope：

    B_K = {
        P ∈ R_+^{K×K} |
        P 1 = 1,
        P^T 1 = 1
    }

训练时使用 soft doubly-stochastic matrix；
测试时再投影到 hard permutation。

注意：
- 仍允许选一个 anchor agent；
- 但 anchor 只用于固定 permutation gauge：
      P_anchor = I
  防止所有 P_i 同时右乘一个相同 permutation 导致全局列编号不唯一；
- anchor 不再作为“所有其他 agent 必须围绕它直接匹配”的中心；
- 所有 graph edges 都必须同时参与全局 objective。

============================================================
四、Pairwise Compatibility 的全局目标
============================================================

对于稀疏图中的边：

    (i,j) ∈ E

构造：

    C_ij ∈ R^{K×K}

其中：

    C_ij[a,b]

表示：

    agent i 的第 a 条未来轨迹
    与
    agent j 的第 b 条未来轨迹

放在同一个 joint future 中的兼容度。

如果 P_i 和 P_j 是 permutation matrices，则：

    Q_ij = P_i P_j^T

表示两个 agent 的样本对应关系。

全局同步目标：

    maximize_{P_i}
        Σ_(i,j ∈ E)
        w_ij < C_ij, P_i P_j^T >

其中：

    <A,B> = Σ_ab A_ab B_ab

训练时：
    P_i ∈ B_K

测试时：
    P_i ∈ permutation matrices

这是新网络最重要的数学核心。

============================================================
五、Trajectory Encoder：必须编码完整 12 帧路径
============================================================

保留并优化当前 trajectory encoder。

输入：

    raw_future:
        [K, T_pred, N, 2]
    或内部：
        [N, K, T_pred, 2]

对每个 agent i、sample a：

    Y_i^a = [y_1,...,y_T]

构造 step feature，至少包含：

    displacement from last observed position: 2
    velocity: 2
    acceleration: 2（建议增加，若当前没有）
    optional normalized time: 1

例如：

    d_t = y_t - x_i_last
    v_t = (y_t - y_{t-1}) / dt
    a_t = (v_t - v_{t-1}) / dt

然后：
- shared MLP / temporal GRU / small temporal Transformer；
- 输出每条候选轨迹表示：

    h_i^a ∈ R^{D_traj}

建议 D_traj=128。

推荐：
- 不使用很重的 Transformer；
- 保持所有 agents / samples 参数共享；
- 对 agent 顺序 permutation equivariant。

============================================================
六、Relation 必须从 edge-level 升级为 trajectory-pair-conditioned
============================================================

旧关系先验：

    q0(r_ij=m | X)

来自观察历史、agent features、edge features。

保留旧 RelationInference 作为 prior，不删除。

但新主模型必须增加 candidate-conditioned relation residual：

    Δl_ij^{ab}
    =
    f_rel(
        h_i^a,
        h_j^b,
        e_ij,
        φ_pair(Y_i^a,Y_j^b)
    )

其中：

    Δl_ij^{ab} ∈ R^M

最终：

    q(r_ij^{ab}=m | X,Y_i^a,Y_j^b)
    =
    softmax_m(
        log q0(r_ij=m|X)
        +
        Δl_ij^{ab,m}
    )

建议：
- M 保持当前 4；
- relation 仍然是 latent modes；
- 不人工规定：
      mode0=朋友
      mode1=避让
      ...
- 训练后通过统计解释；
- relation prior 与 candidate posterior 的差异可以加小权重 KL regularization。

新增配置：

    trajectory_conditioned_relation=True/False
    relation_residual_dim=...
    relation_prior_kl_weight=...
    num_relation_modes=4

消融：
- edge-level relation only；
- trajectory-pair-conditioned relation。

============================================================
七、Trajectory-pair 几何特征
============================================================

对每条 edge (i,j) 和候选对 (a,b)，构造 pair geometric features。

至少包含：

1. endpoint distance：

    d_end^{ab}
    =
    ||Y_i^a(T) - Y_j^b(T)||

2. full-path minimum distance：

    d_min^{ab}
    =
    min_t ||Y_i^a(t)-Y_j^b(t)||

3. mean relative distance：

    d_mean^{ab}
    =
    mean_t ||Y_i^a(t)-Y_j^b(t)||

4. relative trajectory / formation change：

    Δ_rel^{ab}
    =
    (Y_i^a(T)-Y_j^b(T))
    -
    (x_i_last-x_j_last)

5. displacement similarity：

    cos(
        Y_i^a(T)-x_i_last,
        Y_j^b(T)-x_j_last
    )

6. relative velocity similarity / divergence；

7. optional time of closest approach along predicted paths；

8. optional endpoint heading difference。

注意：
interaction != repulsion。

不要加入统一规则：

    “两个人越近，score 一定越差”

因为同行 / companion 可能长期保持近距离。

这些几何量只是 feature，由 relation-conditioned network 学习：
- coordination；
- formation preservation；
- crossing / yielding；
- following；
- weak interaction；
而不是硬编码行为语义。

============================================================
八、Relation-conditioned Trajectory Pair Energy
============================================================

建议使用当前 low-rank goal energy 的思想迁移到 trajectory pair level。

对 edge e=(i,j)、relation mode m、轨迹样本 a,b：

    E_e^m(a,b)
    =
    - w_e
      < A_e^m(a), B_e^m(b) >
      / sqrt(r_t)

其中：

    A_e^m(a) ∈ R^{r_t}
    B_e^m(b) ∈ R^{r_t}

建议：

    r_t = 8 或 16

然后 relation mixture 不使用简单能量平均，而在 compatibility space 中融合：

    E_eff^{ab}
    =
    -logsumexp_m(
        log q(r_ij^{ab}=m)
        -
        E_e^m(a,b)
    )

最终 pair compatibility：

    C_ij[a,b] = - E_eff^{ab}

必须保留：
- low-rank factorization；
- soft latent relation；
- compatibility-space mixture。

新增配置：

    trajectory_energy_type=lowrank
    trajectory_pair_rank=8
    trajectory_relation_mixture=True

消融：
- direct MLP pair score；
- low-rank pair energy。

============================================================
九、Pair-specific Edge Gate
============================================================

旧 Stage 3 只有 edge-level gate：

    g_ij ∈ [0,1]

新主模型需要支持 trajectory-pair-specific gate：

    g_ij^{ab}
    =
    sigmoid(
        f_gate(
            h_i^a,
            h_j^b,
            e_ij,
            q(r_ij^{ab})
        )
    )

然后：

    C_ij[a,b]
    =
    g_ij^{ab}
    ×
    (-E_eff^{ab})

可选加一个 edge-level base gate：

    g0_ij

则：

    g_ij^{ab}
    =
    g0_ij
    ×
    sigmoid(Δg_ij^{ab})

但不要在训练时 detach / hard top-k。

训练：
- 所有 radius+TTC candidate edges 保留；
- gate 连续可微；
- task gradient 可以直接作用到 gate。

推理：
- 若需要控制复杂度，可先计算：

    \bar g_ij = mean_ab g_ij^{ab}

  再对每个 node 取 top-k edges；
- top-k 仅用于 hard inference；
- 默认 top-k=4；
- 配置可关闭。

新增配置：

    pair_specific_gate=True
    inference_edge_topk=4
    use_inference_edge_topk=True

消融：
- no gate；
- edge-level gate；
- pair-specific gate。

十、多路置换同步：核心可微求解器

新增独立模块，例如：

    src/models/permutation_synchronizer.py

输入：
    pair_scores:
        dict / sparse tensor for each edge
        C_ij [K,K]

    edge_strength [E] 或由 pair gate 汇总
    scene_index

输出：

------------------------------------------------------------
10.1 初始化
------------------------------------------------------------

对于每个 connected component：

若 component size = 1：
    P_i = I
    直接 identity。

若 size >= 2：
    选择 anchor：
        weighted graph degree 最大者
    但 anchor 只固定 gauge：
        P_anchor = I

其他：
    P_i 初始为 I 或 uniform doubly-stochastic matrix。

推荐：
    identity initialization
因为 raw GDTS 的列顺序虽然没有理论 joint semantics，但它至少是一个稳定起点，并有利于 no-harm。

------------------------------------------------------------
10.2 图上同步迭代
------------------------------------------------------------

目标：

    maximize Σ_(i,j) w_ij <C_ij, P_i P_j^T>

固定其他 P_j 时，P_i 的一阶 message 可写为：

对于 edge orientation C_ij：
    message from j to i:
        M_{j→i} = C_ij P_j

对于 reverse：
        M_{i→j} = C_ij^T P_i

因此每轮：

    score_i
    =
    (1 / degree_i)
    Σ_{j∈N(i)}
    w_ij * oriented_message(j→i)

然后：

    P_i
    =
    Sinkhorn(score_i / tau_sync)

建议引入 residual：

    score_i
    =
    alpha_identity * I
    +
    alpha_msg * message_i
    +
    alpha_prev * log(P_i_prev + eps)

再做 Sinkhorn。

推荐默认：
    sync_iterations = 3~5
    sinkhorn_iterations = 8
    tau_sync = 0.15~0.3

所有值必须配置化。

anchor 每轮强制：
    P_anchor = I

注意：
- 所有边同时约束 P_i；
- 不再把所有人直接相对 anchor pairwise matching；
- 大 component 中必须利用 entire graph。

------------------------------------------------------------
10.3 伪代码
------------------------------------------------------------

function synchronize(C_edges, edge_index, edge_weight, K):

    P_i = I_K for all i

    components = connected_components(edge_index)

    for comp in components:
        if len(comp) == 1:
            continue

        anchor = argmax(weighted_degree(comp))
        P[anchor] = I_K

        for t in range(sync_iterations):

            message[i] = 0
            degree[i] = 0

            for e=(i,j) in comp.edges:
                C = C_edges[e]          # [K,K]
                w = edge_weight[e]

                # objective <C_ij, P_i P_j^T>
                message[i] += w * C @ P[j]
                message[j] += w * C.T @ P[i]

                degree[i] += w
                degree[j] += w

            for i in comp.nodes:
                if i == anchor:
                    P[i] = I
                    continue

                msg = message[i] / max(degree[i], eps)

                logits =
                    alpha_msg * msg
                    + alpha_prev * log(P[i] + eps)
                    + alpha_identity * I

                P[i] = sinkhorn(logits / tau_sync)

    return P

要求：
- fully differentiable；
- 不 detach；
- 不在训练中 hard top-k；
- variable N；
- E=0、N=1 安全；
- packed multi-scene 时绝不跨 scene。

============================================================
十一、Sinkhorn 实现要求
============================================================

对 logits L ∈ R^{K×K}：

优先使用 log-space Sinkhorn：

    Z = L

repeat T_sink times:
    Z = Z - logsumexp(Z, dim=row)
    Z = Z - logsumexp(Z, dim=col)

最后：

    P = exp(Z)

必须：
- 避免 NaN；
- 支持 batch [N,K,K]；
- eps 可配置；
- 数值稳定；
- 记录 row/column sum deviation。

新增诊断：

    sinkhorn_row_error
    sinkhorn_col_error
    permutation_entropy

============================================================
十二、Hard Projection：必须从 Greedy 改成 Hungarian
============================================================

当前 greedy bijection 只保留作消融。

新默认 hard projection：

    Hungarian / Linear Sum Assignment

目标：

对于每个 non-anchor agent：

    π_i
    =
    argmax_permutation
        Σ_s P_i[π_i(s), s]

或等价对：

    -P_i

运行 Hungarian。

K=20，因此 O(K^3) 完全可接受。

实现优先：
    scipy.optimize.linear_sum_assignment

若工程不希望强制 scipy 新依赖，则实现：
- scipy 路径；
- 无 scipy 时 fallback 到现有 greedy；
- 但日志必须明确 fallback。

新增配置：

    hard_projection=hungarian
    hard_projection=greedy   # ablation

严格检查：
- permutation 每个 index 只出现一次；
- 无重复、无缺失；
- aligned trajectory 仅通过 gather 重排；
- 禁止平均、插值、复制、删除、移动坐标。

============================================================
十三、Component-level Confidence / Identity Bypass
============================================================

保留“有证据才修改”的安全思想，但从 reference-centric 改成 component-level。

对一个 component，计算：

1. identity objective：

    J_id
    =
    Σ_(i,j)
    w_ij < C_ij, I >

2. synchronized soft objective：

    J_sync
    =
    Σ_(i,j)
    w_ij < C_ij, P_i P_j^T >

3. objective gain：

    ΔJ = J_sync - J_id

4. mean permutation entropy；

5. mean pair gate；

6. graph density / component size；

7. cycle/synchronization consistency，可选。

输入 keep_head：

    confidence
    =
    sigmoid(
        f_keep(
            ΔJ,
            entropy,
            mean_gate,
            component_size,
            score_dispersion,
            ...
        )
    )

推理：
    if confidence < keep_threshold:
        所有该 component 的 P_i = I

默认：
    keep_threshold = 0.6

但必须支持：
    use_identity_bypass=True/False
    keep_threshold 可调

注意：
- 不能让 keep_head 初始就强制大量改列；
- 初始化偏向 identity 是合理的；
- 但必须记录 changed_fraction，避免永远旁路。

============================================================
十四、训练损失：直接与联合指标结构对齐
============================================================

新 Stage 的训练输入必须是真实 GDTS 生成的 K=20 条完整轨迹。

不要只在 goal endpoint 上训练新 coupler。

------------------------------------------------------------
14.1 Per-trajectory GT cost
------------------------------------------------------------

对于 candidate trajectory Y_i^a：

    ADE_i^a
    =
    (1/T)
    Σ_t ||Y_i^a(t)-Y_i^GT(t)||

    FDE_i^a
    =
    ||Y_i^a(T)-Y_i^GT(T)||

定义：

    d_i^a
    =
    ADE_i^a
    +
    lambda_fde * FDE_i^a

默认：
    lambda_fde = 1.0

------------------------------------------------------------
14.2 L_alignment：soft joint best-of-K surrogate
------------------------------------------------------------

给 soft permutation P_i[a,s]：

第 s 个联合列的 expected cost：

    J_s
    =
    (1/N)
    Σ_i
    Σ_a
    P_i[a,s] d_i^a

然后对 K 个 joint columns 做 soft-min：

    L_alignment
    =
    -tau_joint
    log Σ_s exp(-J_s/tau_joint)

可选减去常数 tau*logK，使尺度更直观，但保持全工程一致。

默认：
    tau_joint = 0.5

这比直接把 soft P 用于轨迹坐标线性混合更干净：
- 不生成“平均轨迹”；
- 直接优化 expected joint assignment cost；
- 与 JADE/JFDE “同一场景共享 sample index”结构一致。

------------------------------------------------------------
14.3 L_pair_score：监督 C_ij[a,b]
------------------------------------------------------------

对每条 edge 和每个轨迹 pair 构造 oracle pair cost。

不要只用碰撞距离。

推荐：

    pair_gt_cost_ij^{ab}
    =
    0.5 * (d_i^a + d_j^b)
    +
    lambda_rel_geom * R_ij^{ab}

其中 relation geometry error：

    R_ij^{ab}
    =
    (1/T)
    Σ_t
    ||
        (Y_i^a(t)-Y_j^b(t))
        -
        (Y_i^GT(t)-Y_j^GT(t))
    ||

可再加 endpoint relative error：

    +
    lambda_rel_end
    ||
        (Y_i^a(T)-Y_j^b(T))
        -
        (Y_i^GT(T)-Y_j^GT(T))
    ||

该形式不会预设“近=坏”：
- 同行时，保持 GT relative formation 会得到低 cost；
- crossing / yielding 时，只有正确 relative temporal geometry 才低 cost；
- weak interaction 时 individual error 仍占主要部分。

soft target：

    T_ij[a,b]
    =
    softmax_{a,b}(
        -pair_gt_cost_ij^{ab}
        /
        tau_pair_target
    )

predicted pair distribution：

    S_ij[a,b]
    =
    softmax_{a,b}(
        C_ij[a,b]
        /
        tau_pair_pred
    )

loss：

    L_pair_score
    =
    mean_edges
    KL(T_ij || S_ij)

或 soft cross entropy。

------------------------------------------------------------
14.4 L_pair_assignment：直接监督同步后的 pair correspondence
------------------------------------------------------------

由 soft permutations：

    Q_ij = P_i P_j^T

Q_ij 也是近似 doubly stochastic 的 relative assignment。

使用 oracle target T_ij：

    L_pair_assignment
    =
    mean_edges
    KL(
        T_ij
        ||
        normalize(Q_ij)
    )

这个 loss 直接把 pair oracle information 传到 permutation synchronizer，
不要只监督 pair scorer。

新增开关：
    use_pair_assignment_loss=True

------------------------------------------------------------
14.5 L_no_harm：只保护 joint surrogate，不再用于保护 marginal
------------------------------------------------------------

hard permutation 已经严格保护 marginal minADE/minFDE，
所以不需要再用“冻结 + 小步长”去近似保护边际集合。

但为了避免 coupler 无证据时让 joint 变差，保留：

    J_identity_s
    =
    (1/N)
    Σ_i d_i^s

    L_identity
    =
    softmin_s(J_identity_s)

如果：

    L_alignment > L_identity

惩罚：

    L_no_harm
    =
    max(
        0,
        L_alignment - L_identity + margin
    )

默认 margin=0。

------------------------------------------------------------
14.6 L_perm_entropy
------------------------------------------------------------

为了缩小 soft-train / hard-test gap：

    H(P_i)
    =
    -(1/K)
    Σ_{a,s}
    P_i[a,s] log(P_i[a,s]+eps)

    L_perm_entropy
    =
    mean_i H(P_i)

最小化该项，使 P 更接近 permutation vertex。

权重必须小。

------------------------------------------------------------
14.7 L_relation_prior
------------------------------------------------------------

candidate-conditioned relation 不应无约束偏离 observation prior。

可选：

    L_relation_prior
    =
    mean_{e,a,b}
    KL(
        q(r_ij^{ab})
        ||
        q0(r_ij)
    )

权重很小，例如 0.01~0.05 量级，必须配置。

------------------------------------------------------------
14.8 Gate regularization
------------------------------------------------------------

不要强制所有 gate 平均等于 0.5。

可选：
- mild L1；
- target sparsity；
- top-k imitation；
默认权重非常小或 0。

核心是让 task loss 决定 gate。

------------------------------------------------------------
14.9 总损失
------------------------------------------------------------

建议默认：

    L_total
    =
    1.0  * L_alignment
    +
    0.5  * L_pair_score
    +
    0.5  * L_pair_assignment
    +
    2.0  * L_no_harm
    +
    0.02 * L_perm_entropy
    +
    0.02 * L_relation_prior
    +
    0.00 * L_gate_reg

所有权重必须写入 parser/config，不能硬编码。

这只是建议初始值，不代表理论常数。

============================================================
十八、非常重要的新诊断：Alignment Headroom
============================================================

新增指标。

对于某 scene，设每个 agent 的 K 条 trajectory cost：

    d_i^a = ADE_i^a + λ_FDE FDE_i^a

理论上如果只允许对每个 agent 做任意 permutation，
我们可以把每个 agent 自己最优的 trajectory 都安排到同一个 joint column。

因此定义 marginal oracle lower bound：

    J_oracle
    =
    (1/N)
    Σ_i
    min_a d_i^a

raw joint best：

    J_raw
    =
    min_s
    (1/N)
    Σ_i d_i^s

aligned joint best：

    J_aligned
    =
    min_s
    (1/N)
    Σ_i d_i^{π_i(s)}

alignment headroom：

    H_align
    =
    J_raw - J_oracle

recovery ratio：

    rho_recover
    =
    (J_raw - J_aligned)
    /
    max(J_raw - J_oracle, eps)

记录：

    alignment_oracle
    alignment_headroom
    alignment_recovery_ratio

解释：
- headroom 小：候选列本来已接近最优，aligner没有多少空间；
- headroom 大但 recovery 小：coupling solver 不够强；
- headroom 大且 recovery 大：V4有效。

必须按 ETH / UNIV、N 和 component size 分桶。

def forward_multiway_coupling(batch):

    # --------------------------------------------------
    # 1. synchronized observed scene
    # --------------------------------------------------
    obs_world, gt_world, scene_index = load_scene_window(batch)

    # --------------------------------------------------
    # 2. frozen GDTS marginal generator
    # --------------------------------------------------
    with torch.no_grad():
        raw_predictions = gdts_generate(
            batch,
            K=20,
            upstream_generator=args.upstream_generator
        )
        # [K,T_total,N,2]

    raw_future = raw_predictions[:, obs_length:]
    # [K,T_pred,N,2]

    traj_bank = raw_future.permute(2,0,1,3)
    # [N,K,T_pred,2]

    # --------------------------------------------------
    # 3. sparse graph + observation relation prior
    # --------------------------------------------------
    edge_index, edge_feat, base_edge_weight = graph_builder(obs_world)

    with torch.no_grad() if freeze_old_social else nullcontext():
        agent_feat = social_encoder(obs_world, edge_index, edge_feat)

        q0_relation = old_relation_inference(
            agent_feat,
            edge_index,
            edge_feat
        )
        # [E,M]

    # --------------------------------------------------
    # 4. encode every complete trajectory candidate
    # --------------------------------------------------
    traj_feat = trajectory_encoder(
        traj_bank,
        last_obs=obs_world[:,-1]
    )
    # [N,K,D]

    # --------------------------------------------------
    # 5. build all sparse edge trajectory-pair features
    # --------------------------------------------------
    pair_geom = build_pair_geometry(
        traj_bank,
        last_obs,
        edge_index
    )
    # [E,K,K,D_pair]

    # --------------------------------------------------
    # 6. candidate-conditioned relation posterior
    # --------------------------------------------------
    relation_prob_ab = trajectory_relation(
        traj_feat,
        pair_geom,
        edge_index,
        edge_feat,
        q0_relation
    )
    # [E,K,K,M]

    # --------------------------------------------------
    # 7. relation-conditioned low-rank energy
    # --------------------------------------------------
    pair_energy = trajectory_energy(
        traj_feat,
        pair_geom,
        edge_index,
        edge_feat,
        relation_prob_ab
    )
    # effective energy [E,K,K]

    # --------------------------------------------------
    # 8. pair-specific gate
    # --------------------------------------------------
    pair_gate = pair_gate_module(
        traj_feat,
        pair_geom,
        edge_index,
        edge_feat,
        relation_prob_ab
    )
    # [E,K,K]

    pair_score = -pair_energy * pair_gate
    # [E,K,K]

    # --------------------------------------------------
    # 9. graph-wide multiway permutation synchronization
    # --------------------------------------------------
    sync_output = synchronizer(
        pair_score,
        edge_index,
        pair_gate.mean(dim=(1,2)),
        scene_index
    )

    P_soft = sync_output["soft_permutation"]
    # [N,K,K]

    # --------------------------------------------------
    # 10. training losses
    # --------------------------------------------------
    if training:
        loss_dict = coupling_loss(
            P_soft=P_soft,
            pair_score=pair_score,
            relation_prob_ab=relation_prob_ab,
            relation_prior=q0_relation,
            raw_future=traj_bank,
            gt_future=gt_world[:,obs_length:] or normalized layout,
            edge_index=edge_index,
            pair_gate=pair_gate
        )

        return loss_dict, diagnostics

    # --------------------------------------------------
    # 11. hard inference
    # --------------------------------------------------
    hard_perm = hungarian_project(P_soft)

    hard_perm = component_identity_bypass(
        hard_perm,
        confidence=sync_output["confidence"],
        threshold=args.keep_threshold
    )

    aligned_future = gather_only(
        traj_bank,
        hard_perm
    )

    # exact set preservation check
    assert_same_per_agent_sample_set(
        traj_bank,
        aligned_future
    )

    return aligned_future, raw_future, diagnostics

def project_to_permutation(P):
    # P [K,K], rows=original candidates, cols=joint slots

    row_ind, col_ind = linear_sum_assignment(-P.detach().cpu().numpy())

    # want perm[s] = original_candidate_a
    perm = empty(K)
    for a, s in zip(row_ind, col_ind):
        perm[s] = a

    assert sorted(perm) == list(range(K))
    return perm

aligned[i,s] = raw[i, perm_i[s]]

def compute_loss(P, pair_score, raw_future, gt_future, edge_index):

    # raw_future [N,K,T,2]
    # gt_future  [N,T,2]

    ade = norm(raw_future - gt_future[:,None], dim=-1).mean(dim=-1)
    # [N,K]

    fde = norm(raw_future[:,:,-1] - gt_future[:,-1,None,:]? fix actual layout)
    # [N,K]

    d = ade + lambda_fde * fde
    # [N,K]

    # expected cost per joint slot
    # P[n,a,s]
    J = einsum("nas,na->ns", P, d).mean(dim=0)
    # [K]

    L_alignment = softmin(J, tau_joint)

    J_identity = d.mean(dim=0)
    L_identity = softmin(J_identity, tau_joint)

    L_no_harm = relu(L_alignment - L_identity)

    pair_targets = []
    pair_assign = []

    for e=(i,j):
        R = relative_geometry_error(
            raw_future[i],
            raw_future[j],
            gt_future[i],
            gt_future[j]
        )
        # [K,K]

        pair_cost =
            0.5*(d[i,:,None] + d[j,None,:])
            + lambda_rel_geom*R

        T_ij = softmax(-pair_cost/tau_pair_target)
        S_ij = softmax(pair_score[e]/tau_pair_pred)

        L_pair_score += cross_entropy_soft(T_ij, S_ij)

        Q_ij = P[i] @ P[j].T
        Q_ij = Q_ij / Q_ij.sum()
        L_pair_assignment += KL(T_ij || Q_ij)

    L_perm_entropy = entropy(P).mean()

    L_relation_prior = KL(
        relation_prob_ab,
        relation_prior[:,None,None,:]
    ).mean()

    return (
        lambda_alignment * L_alignment
        + lambda_pair_score * L_pair_score
        + lambda_pair_assignment * L_pair_assignment
        + lambda_no_harm * L_no_harm
        + lambda_perm_entropy * L_perm_entropy
        + lambda_relation_prior * L_relation_prior
    )

注意上面 fde 的索引只是伪代码。
实现时必须根据项目真实 tensor layout 修正，不允许照抄错误维度。

============================================================
二十八、Permutation Synchronization 的方向一致性
============================================================

这是容易写错的地方，必须单元测试。

定义：
    C_ij[a,b]
    row = candidate of i
    col = candidate of j

目标：
    <C_ij, P_i P_j^T>

所以：

    grad-like message to i:
        C_ij @ P_j

    message to j:
        C_ij.T @ P_i

不要把转置方向写反。

必须加入人工小例子单测：
- K=3；
- 手工构造已知最优 permutation；
- 检查 synchronizer + Hungarian 能恢复正确 mapping。

============================================================
二十九、Cycle / Global Consistency 诊断
============================================================

虽然新模型直接优化 P_i，因此理论上 pairwise relative assignment：

    Q_ij = P_i P_j^T

天然来自同一组 global P_i，
比独立 pairwise matching 更一致。

仍建议加入诊断：

对三角形 i-j-k：

    Q_ij Q_jk ≈ Q_ik

记录：

    cycle_consistency_error

训练主损失默认不一定启用，
但必须可计算。

这对 UNIV 大 component 很重要。

============================================================
三十、必须保留的理论保护
============================================================

硬推理后必须保证：

对每个 agent i：

    sorted(permutation_i) == [0,1,...,K-1]

不允许：
- duplicate sample；
- missing sample；
- coordinate averaging；
- soft interpolation；
- continuous refinement；
- 删除轨迹；
- 添加新轨迹。

因此最终 aligned set 与 raw set 完全相同。

验证时加入自动 assert：
- raw/aligned minADE 一致；
- raw/aligned minFDE 一致。

若不一致：
    立即报错，而不是继续训练/测试。

    γ

    γ_i = μ_i

    C_ij[a,b]
    =
    g_ij^{ab}
    ×
    log
    Σ_m
    q(r_ij^{ab}=m)

        -E_ij^{m}(a,b)

    max_{P_i ∈ B_K}

    P_i ∈ B_K

============================================================
四十、关键设计原则
============================================================

必须遵守：

1. 解决 UNIV 问题优先依靠：
   global multiway consistency，
   而不是继续堆网络深度。

2. reference agent 仅可作为 gauge anchor，
   不能再成为所有人的唯一匹配中心。

3. relation 必须能依赖具体 future hypothesis。

4. interaction 不等于 collision avoidance。

5. pair gate 训练时不能 detach 后裁边。

6. hard inference 必须默认 Hungarian。

7. 不再使用 continuous trajectory / goal coordinate refinement。

8. 不重新设计 diffusion。

9. 不显式枚举 K^N。

10. 所有 social/coupling 计算只在同步 scene/window 内进行。

11. world-coordinate 交互计算必须统一用米。

12. 任何排列都必须严格双射。

13. 所有旧方法必须可通过 config 恢复用于消融。

14. 不要为了“看起来复杂”额外增加无必要模块。
