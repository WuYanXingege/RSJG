# BCEP–EBJD 联合评分可辨识性与软硬分配审查

**结论：已有足够证据支持把“同一场景能量产生候选替换评分”实现为下一版待验收机制；没有证据宣称它已能改善 JADE/JFDE，也没有启动下一次训练的授权。** 当前问题在旧 v2 已经存在。v3 相对旧 epoch 5 的有效区分度更低，但相对旧 epoch 26 更高，不能把它归因为 v3 独有或单一新增模块的退化。

本轮真实 optimizer updates **0**，合成 optimizer updates **0**，DDIM 新调用 **0**；仅冻结前向、受控参数梯度及 CPU 数学原型。未重选模型、未用测试集、未改正式网络、未恢复任何旧队列。42,650 个历史资产文件、12,547,558,589 字节逐一复核，内容与清单均未改变；v3 原 30 轮/5040 次历史更新完整保留。参见 [资产收据](ASSET_RECEIPT.json)。

## 2. 原始幅度大，不代表能够识别完整匹配

对每位行人的 K×K 评分 S，令 J=I−11ᵀ/K，有效评分为 S_eff=JSJ，即双重去均值。任意双射 π 都满足

\[
\sum_w S_{w,\pi(w)}=\sum_w(S_{eff})_{w,\pi(w)}+K\bar S.
\]

因此，行列可加项的幅度不能支持“匹配区分能力充足”的结论。以下连续量均先在人内平均，再按 **501 个多人窗口等权**；间隔和并列计数以 4173 个有效行人矩阵为单位。

| 模型/阶段 | 原始 RMS | 有效 RMS | 有效能量/原能量 | 完整 gap 中位数 | 严格并列数 / 4173 |
|---|---:|---:|---:|---:|---:|
| v2 e5 初配 | 4.92670e−2 | 7.99747e−7 | 6.78707e−10 | 7.45058e−9 | 864 |
| v2 e5 最终 | 4.93556e−2 | 2.85167e−6 | 8.94084e−9 | 1.86265e−8 | 242 |
| v2 e26 初配 | 4.25480e−2 | 1.03764e−7 | 2.49134e−11 | 1.86265e−9 | 1961 |
| v2 e26 最终 | 4.24946e−2 | 2.36988e−7 | 1.16980e−10 | 3.72529e−9 | 836 |
| v3 e12 初配 | 4.18982e−2 | 2.12963e−7 | 7.79770e−11 | 3.72529e−9 | 1634 |
| v3 e12 最终 | 4.18929e−2 | 7.52895e−7 | 9.86220e−10 | 7.45058e−9 | 389 |

旧 e5→e26 的最终有效 RMS 约缩小 12 倍；v3 约为 e5 的 26.4%，又约为 e26 的 3.18 倍。这支持“旧结构已存在近可加评分、后期 checkpoint 更弱”的观察，不足以确定训练过程的因果来源。不同模型的评分单位由各自参数决定，所以 RMS 跨模型比较还须结合相同原生 Sinkhorn、特征差异、间隔与实际匹配。

### 谱：能量集中，不等于代数秩只有 1

在已知零和的 K−1=19 维子空间计算有效谱，并显式保留一个数学零奇异值，避免大行列项的 FP64 消减误差伪造第 20 个维度。各矩阵以 FP64 相对阈值计算的有效秩都是 19；FP32 相对阈值下，多人最终评分的窗口等权平均秩为 18.967/18.997/18.996。**不能声称矩阵严格低秩或精确可加**。

| 最终评分 | 稳定秩 ‖S_eff‖²_F/σ₁² | 第一奇异值能量占比 | 前五能量占比 |
|---|---:|---:|---:|
| v2 e5 | 1.14622 | 89.0331% | 99.9570% |
| v2 e26 | 1.43910 | 71.6602% | 99.3262% |
| v3 e12 | 1.28225 | 80.4064% | 99.2919% |

完整 20 个奇异值、能量谱、稳定秩、熵有效秩和分位数已导出。还单列了高于 `K·eps_fp32·max|S|` 保守输入舍入界的奇异值数量；这是尺度参照，不是“界以下必定无效/全是噪声”的判定。

## 3. 完整匹配间隔与编号敏感性

次优完整匹配通过逐一禁止最优排列的 20 条已选边，再求其中最佳替代得到，不是逐行 top2 差。使用原 FP32 评分的 FP64 求和；gap=0 记严格并列，0<gap≤1e−6 记近并列。1e−6 是固定诊断分箱，不是优化或评测阈值，也不等于证明所有这些解在 FP32 中无法区分。

每个模型两个阶段的所有 4173 个多人矩阵均为严格/近并列，没有超过该阈值的矩阵。最终评分最大 gap 分别为 4.20958e−7、8.94070e−8、1.82539e−7。近并列可能由大量候选组合共同造成，单凭小 gap 不能证明模型无用；本报告结合有效评分、特征、软梯度和实际换配一起判断。

固定重编号操作为 world 行反转、候选列循环移位一位，再映射回原编号。未重新计算评分。

| 模型/阶段 | 映射回后改变的行人匹配数 | 改变的 world–candidate 格数 | 原目标值损失 |
|---|---:|---:|---:|
| v2 e5 初配 / 最终 | 325 / 70 | 899 / 167 | 均 0 |
| v2 e26 初配 / 最终 | 1041 / 378 | 3579 / 1097 | 均 0 |
| v3 e12 初配 / 最终 | 799 / 155 | 2503 / 418 | 均 0 |

这些变化全部发生在严格并列矩阵；本次固定重编号下，正 gap 近并列矩阵未改变最优匹配。这里只检验一种重编号，不宣称所有重编号、浮点扰动下都稳定，更不宣称无条件排列等变。

复用的关键反例：v3 窗口 **2978**，3 人，匿名 person 1，最终 gap=0；重新编号使该人 3 格选择改变，完整评分目标值差严格为 0，但窗口 JFDE 从 1.1971740723 m 变成 1.0223580599 m，差 −0.1748160124 m。它只改变一位行人的对应关系，并非全场景统一换 world 编号；证明同分分配也可能有不同物理结果，不能把无损的数学重编号等同于跨人配对不变。该反例来自既有回放，不是本轮挑出的新模型结果。

人数分组表在 [SCORE_SUMMARY.csv](SCORE_SUMMARY.csv)、[TIES_SOFT_HARD_GROUPS.csv](TIES_SOFT_HARD_GROUPS.csv)。N≥9 的最终有效 RMS 分别为 2.68184e−6 / 1.78139e−7 / 5.80019e−7，严格并列为 131 / 419 / 184（每模型分母 2549 个行人矩阵）；密集场景也存在同样现象。

## 4. 原生 Sinkhorn 与硬分配确实处在不同状态

严格调用源码的 FP32 `log_sinkhorn(scores, 20)`，评分温度为原值 1，没有调温、评分倍数、额外噪声。以下是多人最终矩阵的窗口等权平均。

| 模型 | ‖P_soft−1/20‖_F | 最大元素 | H 对应位置上的平均软概率 | hard–soft 每行 TV |
|---|---:|---:|---:|---:|
| v2 e5 | 2.85496e−6 | 0.0500006796 | 约 0.05 | 0.949999840 |
| v2 e26 | 2.75925e−7 | 0.0500000546 | 约 0.05 | 0.949999999 |
| v3 e12 | 7.69416e−7 | 0.0500001718 | 约 0.05 | 0.949999961 |

归一化行熵 H/log20 均大于 0.999999999998；最终全部多人矩阵的最大行/列和误差不超过约 2.43e−7。严格并列与正 gap 近并列两组都如此；行列约束已经满足，继续将这一现象解释成“20 次 Sinkhorn 没收敛”没有数据支持。逐矩阵熵、极值、边缘和误差、hard–soft Frobenius/TV、argmax 一致率及分组分布均在 CSV 中。

单人 89 窗是原生 identity bypass：soft=hard=I，熵为 0、hard–soft 距离为 0、配对梯度为 0。这是设计行为，不是退化失败；不能将其与多人直接混合后得到一个虚假的“软排列更尖锐”结论。全体 590 窗的统计仍完整导出。

## 5. 实测梯度：非零，但不代表硬匹配方向正确

每个人数分箱 1、2–4、5–8、9–12、13–20、21+，按官方 dev 顺序均匀取 6 个位置，共 36 窗；三个模型使用完全相同的窗口。每模型 30 个多人样本，18 个 N≥9 样本。只计算原 final_coordinate 的 pair loss：不增广、不采训练噪声、不混其他损失、不裁剪、不构造优化器、不写参数 `.grad`。这不是重放历史完整 minibatch 的优化器梯度。

cuDNN GRU 不支持 eval 模式反传，因此正式审计图使用原 train 模式；已逐模块确认 dropout 为 0、没有 BatchNorm。全部 **108 个最终使用的受控前向**，S0/最终评分及初配/终配均与缓存推理逐值一致。模型 state_dict 前后哈希不变。第一次 eval 反传失败及后续数值核对均未执行 optimizer 更新，见代码审计记录。

令 g_P=∂L/∂P_final、g_S=∂L/∂S_final。在均匀 Sinkhorn 附近，理论局部预测为 g_S≈Jg_PJ/K。本轮**实际测量**该 VJP，而不是由软矩阵外观推断梯度消失：

| 模型 | 多人 ‖g_S‖ 中位数 | 实测 ‖g_S‖/‖Jg_PJ‖ 中位数 | 均匀 Jacobian 预测相对残差中位数 | 初配反馈间接梯度/最终直接梯度中位数 |
|---|---:|---:|---:|---:|
| v2 e5 | 0.0509466 | 0.04999999 | 2.33258e−6 | 1.30326e−6 |
| v2 e26 | 0.0594895 | 0.05000000 | 5.07748e−7 | 7.93584e−8 |
| v3 e12 | 0.0511153 | 0.05000000 | 7.62592e−7 | 2.86848e−7 |

因此“Sinkhorn 均匀 ⇒ score 梯度消失”被本轮数据否定。另一方面，硬排列由极小评分差决定，反向仍几乎是均匀软分配的局部导数；这是一种已测得的软硬状态不一致。它本身**没有证明梯度与真实硬 JFDE 变化一定同向或反向**，本轮没有把局部导数冒充离散交换效果。

三个模型的30个多人梯度样本中，分别有17、24、19个窗口包含最终评分严格并列的行人矩阵；这些窗口全部测得非零场景 score 梯度。这里是“含并列窗口”的证据，不能据此断言窗口内每一个并列行人子矩阵都具有相同梯度范数；逐窗并列构成已单列。

间接路径单独测量：先取得原图对 initial_ST 的伴随梯度，再通过原初配 Sinkhorn 做 VJP。不能简单把两个几乎相同的 FP32 score 梯度相减作为主证据。作为交叉检查，`g_initial_total−g_final_direct` 与单独 VJP 的差相对直接梯度约 2.1e−8～3.15e−8；相对极小间接梯度可达 51.6%，这是相消精度限制，已保留在 CSV 中，没有隐去。

参数级实测：所有模型的共享编码器、world_queries、场景注意力、评分 MLP、旧反馈参数在 30/30 多人样本得到非零 pair 梯度。v3 CSEE、HCRA 同样为 30/30；梯度范数中位数分别约 1.83584e−7、2.17681e−4。单人样本的配对梯度为 0。桥的 denoiser/GRG 不在这个 pair loss 计算图上，梯度 unused 是源码路径的预期结果，不能据此说它们没有从其他训练损失学习。

本轮所有参数更新仍为零；范数小不判为失败，不跨不同参数数目和尺度的模块直接比较“贡献大小”。新增结构在历史训练中的独立贡献，不能由这次冻结 VJP 归因。

## 6. 推荐与停止判断

唯一优先方向：**把旧反馈与 HCRA 的独立接收者评分，改为来自同一 scene/world 能量的条件候选替换评分，并以有界顺序更新协调各人的修改。** 设计输入、张量、公共势、非可加四点差、软扩展、Hungarian/Sinkhorn/final_coordinate 接口、57 人成本、并列处理均在 [结构设计文档](SCENE_ENERGY_DESIGN_ZH.md)。

CPU 原型的 10 项测试通过；在 N=57、K20、全连接最坏 1596 条无向边上，一次包含精确次优检查的 sweep 为约 0.80 秒、1197 次 20×20 Hungarian。FP32 候选关系表约 2.55 MB。该计时只覆盖表能量数学原型，不包含拟议 φ/ρ 网络前后向，不能当作正式训练提速或可用吞吐的证明。

证据边界如下：

| 判断 | 本轮证据 |
|---|---|
| 近可加评分是 v3 新引入的吗？ | 否，旧 e5/e26 已有；v3 强于 e26、弱于 e5的有效区分度 |
| world 区分不足有直接测量吗？ | 有，S0 场景注意力后特征差异显著收缩；不能推广到全部 HCRA 特征 |
| 软硬状态不一致有直接测量吗？ | 有，soft 接近均匀、hard 为双射；原生 VJP 接近均匀 Jacobian |
| 所有梯度消失或损失完全断路吗？ | 否，多人 score 和相关模块均有非零梯度；初配反馈间接路径很弱 |
| 当前评分的小间隔一定导致指标退步吗？ | 尚不能作完整因果归因；同分解不同 JFDE 是直接反例，但不足以解释全部误差 |
| 公共能量一定会改善 JADE/JFDE 吗？ | 未知；原型只验证数学一致性和容量，不含学习效果 |
| 是否值得实现下一版正式机制？ | **是，值得实现并做零更新工程验收；尚不等于具备启动训练的证据或授权** |

没有提出新损失权重、温度搜索或新增注意力层；没有启动 v4、第二 seed、其他折、测试集、消融训练或旧队列。后续需要在实际神经实现中验证可学习势、初配 incumbent 的并列依赖、精确候选/噪声键对应、条件路径梯度及计算成本，完成后再等待独立训练决策。
