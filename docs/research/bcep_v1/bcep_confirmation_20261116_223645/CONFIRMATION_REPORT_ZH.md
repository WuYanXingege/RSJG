## 主要结论

**固定KMeans的收益迁移到了本轮留出录制，但Flow优于MDN8的方向没有跨训练seed保持一致。** Flow+KMeans的两训练seed平均minFDE为 **0.255414 m**，MDN8+KMeans为 **0.265643 m**（差 -0.010229 m，平均降低 3.85%）。这不是稳定优势或替代旧Provider的证明。
- KMeans相对IID的minFDE平均降低：Flow 19.91%，MDN8 19.79%；四个run的minFDE、P90、P95及Recall@0.5/1.0均改善，支持固定候选压缩具有实际价值。
- 同时四个run的P50均升高、Recall@0.25均降低：改善主要体现在平均误差及较大误差区间，不能写成所有精度尺度都改善。这里只描述误差分布取舍，不据此推断具体因果机制。
- Flow−MDN8的minFDE在3102为 -0.024935 m，在3103为 +0.004477 m；Flow的P90和Recall@0.5均较好，但P95两次均较差，合并P95差 +0.008729 m。连续密度NLL的优劣同样随训练seed反转。保留Pareto取舍，不挑有利seed。
- 单人组77窗口/77次出现，多人组921窗口/5833次出现；总表主要由多人出现贡献。单人组Flow的minFDE两次均较好，多人组仍呈两seed方向反转，因此人数分组没有消除总体的随机性问题。单人样本量小，不作显著性结论。
- Flow两组训练墙钟各约41–42分钟，MDN8各约16分钟；两者完成相同6轮和16752更新。更高Flow训练成本也应计入方案选择，不能只展示较低的汇总误差。
- 工程与确认流程均完成；尚未建立旧matched Provider的同确认协议对照，也未训练联合桥。因此 PROVIDER_REPLACEMENT=NOT_ESTABLISHED，FULL_EBJD_PERFORMANCE=NOT_EVALUATED。
