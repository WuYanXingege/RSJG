# ZARA1 / ZARA2 开发集整组交换实验

当前为启动归档，尚无本次真实配对评分结果。后台完成后此处将更新为两折中文报告及CSV。

固定资产：ZARA1 B epoch6（671 dev窗，181 dense窗），ZARA2 B epoch35（590 dev窗，127 dense窗）。seed=2035，M=256，K=20，20步DDIM，eta=0，关闭1 cm校准，训练更新0，测试访问0。已有四折控制器照常执行。

原B调用原生select_joint_samples。新方案从相同S0出发，穷举整组一换一，保持最初J0，选P最小的合格交换；P须下降超过1e−12 m，完全同分按换出/换入原始编号排序，换入项占原槽。没有合格交换才停止。逐次直接复算J/P，不添加轮次限制或放宽约束。

两人LL/LR/RL/RR例子和小规模逐步穷举对照已验证。推理用低并发CPU，两路共用原始候选，分别整组修正一次、实际20步DDIM一次。每个原始编号使用相同桥噪声。零交换窗保留。两折全部预测封存后才读取dev未来评分。

固定入口：`python -m whole_scene_swap.run`。结果将包含四项原生指标、换组统计、J/P、约束违反数及同设备耗时。2 cm仅为研发目标解读，不用于搜索配置或筛选窗口。权重、候选和原始轨迹留在训练主机。
