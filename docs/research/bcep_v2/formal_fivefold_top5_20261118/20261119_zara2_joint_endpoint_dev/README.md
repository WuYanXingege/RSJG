初次配对、邻居反馈均有平均改善的直接证据。第 26 轮在 32 个多人窗口抽查 1280 个交换；1224 个两侧非近零交换中，方向不一致 482 个（39.38%）。这是有限离散交换与局部坐标代理的机制诊断，不是新模型评测，不能将全部误差归因于训练梯度。
