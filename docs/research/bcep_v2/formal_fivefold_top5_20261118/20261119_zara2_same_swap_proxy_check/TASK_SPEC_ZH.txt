二、对每一行计算真实代价和两个代理
记 g[i,a] 为候选坐标，y[i] 为真实未来最后一帧，pi[k,i] 为世界 k 中分配给行人 i 的候选。令 D[i,a]=||g[i,a]-y[i]||₂，N 为该窗口有效人数。使用 K=20、τ=0.1 m，FP64 计算及稳定 logsumexp。先对同一世界内的行人求平均，再对世界做 softmin。保留原来 pair_loss 的归一化常数。

伪代码：
  X[k,i] = g[i,pi[k,i]]
  e[k]   = mean_i D[i,pi[k,i]]
  C(e)   = -τ * (logsumexp(-e/τ) - log(K))
  w      = softmax(-e/τ)                         # 在交换前计算

  # 本行只交换行人 i 的两个世界 u、v；其他行人保持原样
  a, b  = pi[u,i], pi[v,i]
  delta = (D[i,b] - D[i,a]) / N
  de    = zeros_like(e); de[u] = delta; de[v] = -delta
  true_delta = C(e + de) - C(e)

  # 旧：实际选中坐标处的方向导数，与原 diagnose_gpu.py 交叉核验
  X_swap = X.clone(); X_swap[u,i], X_swap[v,i] = X[v,i].clone(), X[u,i].clone()
  s_coord = sum(grad_X C(mean_i norm(X-y)) * (X_swap-X))

  # 新：候选代价线性混合后，在同一硬排列点的方向导数
  s_cost = dot(w,de)                             # 等于 (w[u]-w[v])*delta

注意 s_cost 是代理，不得拿 true_delta 当作新代理。两种代理都在最终分配矩阵处、Sinkhorn Jacobian 之前衡量。交换后的真值代价必须重新做 softmin，不能固定旧 w 计算。真值只用于离线监督与计分。
