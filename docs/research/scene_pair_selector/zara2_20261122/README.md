## 真实切换与浮点回放

一个动作切换整个窗口、全部有效行人及 20 个联合场景。以下改善/恶化/持平只统计实际切到 I 的窗口，相对同次独立强制 H0；未切换的窗口不计入切换收益。

| 分组 | 切换窗数 | JADE 改善 / 恶化 / 持平 | JFDE 改善 / 恶化 / 持平 |
|---|---:|---|---|
| all | 195 | 95 / 91 / 9 | 102 / 84 / 9 |
| N_ge_9 | 48 | 26 / 22 / 0 | 27 / 21 / 0 |

逐窗分解为 `实际−同次H0 = 切换指示×(同次I−同次H0) + 回放残差`。最大绝对回放残差为 JADE 0 m、JFDE 0 m。两组各自平均切换贡献、残差均保存在 [PAIRED_SUMMARY.csv](PAIRED_SUMMARY.csv)。相对固定历史门槛，同次 H0 的三项回放差为 [2.0204965478498593e-10, 0.0, 7.743910623858596e-09] m；没有将该差解释为模型收益，也没有修改门槛。另附 [H0 逐窗历史回放差](H0_ARCHIVE_REPLAY_DIFFERENCES.csv)。

## 标签、模型与边界

冻结旧 v2 coordinate epoch5；原生源码 `468c5eddde48bdeec47c4bb3c39418352be16bb9`，权重 SHA256 `9281673fda5c439bdd463b0bfc9af1a65a3a0fea30941ad3c956cbb617943317`。Provider density19/head9、共享编码器、配对头和六层桥均 eval、无梯度，训练前后张量哈希完全一致。train 2681 窗和 dev 590 窗使用原 split、seed2035 refined bank 和按 scene/agent/原 bank 槽位生成的 keyed noise。

I 为同一次原配对前向第一次 Hungarian 的排列，H0 为 S0 加旧邻居反馈后的第二次排列；原 bank 顺序 G 未当作 I。离线分别解码两路，端点与原槽位噪声同步 gather。标签为 `dA=JADE(I)−JADE(H0)`、`dF=JFDE(I)−JFDE(H0)`，单位米。共享图打分器有 18,562 个参数，以历史、冻结 social_h 和同一联合场景内的配对终点关系为输入；窗口 ID、未来、误差标签均不进入打分器。归一化仅拟合 train。双输出 MSE 按窗口等权。

规则固定为 `dA_hat≤0 且 dF_hat<0` 时选 I，其余 H0；单人或排列完全相同直接 H0。对照事后选择的全体/N≥9 JFDE 为 0.730725187884/1.243030111386 m，仅用于描述选择空间，不作为正式成绩或调参依据。原归档 H0 相对 I 的改善/恶化/持平为 234/249/107；本次原生轨迹 metric 为 232/247/111。其中 4 个窗口的近零差变为持平，I 的 JFDE 最大回放差为 5.9604644775390625e-08 m，详见 [数值差异记录](METRIC_NUMERICS.json)。未以容差改写标签或选择规则。

FP32、原 AdamW 参数分组，lr=1e-4、weight_decay=1e-4、5 轮 warmup、100 轮 cosine horizon，minimum30/patience15/max100。优化器只含选择头。三个真实窗口的强制 H0 与旧入口逐值一致；最终复核 590 窗，每窗先决策后只解码选中分支一次，另做两条离线强制对照。
