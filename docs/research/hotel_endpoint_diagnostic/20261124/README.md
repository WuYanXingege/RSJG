## 唯一下一步

**可立项一种兼顾个人覆盖的整场选择准则，并把动静混合窗的真实JFDE列为后续开发集验收项。** 同为K20时，原生整场选择在全员运动窗损失边缘覆盖，同时在混合窗保住联合收益；此权衡在旧头前已经出现，旧头后方向仍然存在。
