## 计算成本与复现

K21 只用于诊断。I 为 S0 减 K21，D 为新 K20 减 K21，逐窗与汇总均核验 Δ＝D−I。线上仍需先生成 S0 的全部 20 个场景，再替换一槽。新匀速场景无需调用桥。

两项任务到归档生成的总墙钟为 330.53 秒。已实际新增 DDIM 调用 UNIV 0 次、HOTEL 0 次。

UNIV 首次启动时修正了历史封存清单读取。实际运行使用逐窗逐种子记录校验人数和哈希。修复前的尝试在生成新预测、读取测试真值之前退出。
