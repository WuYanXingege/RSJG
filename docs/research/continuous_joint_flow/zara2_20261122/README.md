# ZARA2 连续联合终点生成实验结果

同一 rank1 的 B 同时满足三项固定门槛，ZARA2 单折通过；不据此扩展到其他折。

本轮只训练一个跨人依赖网络，seed 固定为 3201。实际完成 **50** 轮、**8400** 次更新，停止原因为 `early_stop`。每轮均将新模型的真实 K20 预测经过一次 20 步 DDIM，在全部 590 个 dev 窗口上计算原生指标；仅按全体 dev JADE 最低选出的 rank1 为第 **35** 轮，严格同分取较早完整轮次。最终 B/C/D 均使用该 rank1；没有第二个模型、第二个训练 seed、测试集访问或扩折。

## 连续似然与依赖机制

连续模型的 ΔNLL 为相对独立标准高斯的负对数似然差，单位 nat/人，各窗口等权。其计算对象是**压缩前的连续终点分布**；冻结 Flow 的 Jacobian 在差值中抵消。C 的理论 ΔNLL 恒为 0，不能为 A 或 D 虚构同一种连续模型似然。

| 分组 | B：dev ΔNLL (nat/人) | C：dev ΔNLL | B−C |
|---|---:|---:|---:|
| 全体 | -0.0740154282291 | 0 | -0.0740154282291 |
| N≥9 | -0.0288151547159 | 0 | -0.0288151547159 |

**全体：**B 相对 C 的连续 ΔNLL 下降 0.0740154282291 nat/人，JFDE 下降 0.0404500149885 m；在每人终点集合相同的 B/D 对照中，保留 B 的跨人对应关系使 JFDE 相对 D 下降 0.0495475777971 m。
**N≥9：**B 相对 C 的连续 ΔNLL 下降 0.0288151547159 nat/人，JFDE 下降 0.00987953886272 m；在每人终点集合相同的 B/D 对照中，保留 B 的跨人对应关系使 JFDE 相对 D 下降 0.0160736241679 m。

| 分组 | B−A JADE | B−A JFDE | B−C JADE | B−C JFDE | B−D JADE | B−D JFDE |
|---|---:|---:|---:|---:|---:|---:|
| 全体 | -0.0312660861192 | -0.0655503071489 | -0.0151616257 | -0.0404500149885 | -0.0197718094668 | -0.0495475777971 |
| N≥9 | -0.0486833223208 | -0.107038200606 | -0.00136290255963 | -0.00987953886272 | -0.00823964058884 | -0.0160736241679 |

差值为逐窗配对差的均值，负值表示 B 较低。B/C 回答学习跨人依赖后的实际变化，依赖可能进一步改变后续代表样本和修正结果。B/D 在每人终点集合固定时检查联合对应关系：2950 个“窗口×置乱”检查的终点集合完全相同，2950 个检查的每人端点 minFDE 完全相同。桥解码后的每人 minFDE 最大绝对数值差为 **0 m**，单列于 [五次置乱逐窗记录](D_SHUFFLE_WINDOWS.csv)，没有混同于端点集合变化。

A/B 是完整方案差异，包含连续采样、压缩策略和后续路径的影响，不能单独归因于依赖网络。预测门槛判定与机制方向分别报告；单折结果不作为跨折结论。

严格保持的是**压缩前每个人的连续 Flow 边缘分布**：共享边因子与独立个人噪声均为标准高斯，经各人的 Cholesky 白化后，联合高斯的每个对角块为 I₂。有限的 256 次抽样仍有经验覆盖波动；整组压缩和有界修正不承诺保留该连续边缘分布，其变化由上述实测量描述。

## 固定实现与训练

冻结基线为旧 v2 coordinate epoch5，原生提交 `468c5eddde48bdeec47c4bb3c39418352be16bb9`，checkpoint SHA256 `9281673fda5c439bdd463b0bfc9af1a65a3a0fea30941ad3c956cbb617943317`。Provider density epoch19、修正头 epoch9、原编码器和六层桥全程 eval、无梯度，训练前后张量哈希完全一致。train 2681 窗、dev 590 窗，dev 中 127 窗 N≥9；未加载测试数据。SSEC 保持其原监督器记录的暂停状态，旧 I/H0 选择实验不重启。

依赖网络是共享的 260→64→4 两层 MLP，共 **16,964** 个可训练参数，SiLU 激活，从边两端各自的视角读取两个冻结 Flow 观测上下文、相对位置和相对速度，输出 2×2 实矩阵。图取旧观测近邻图的无向并集。末层权重以 std=0.001 初始化，偏置为 `[0.02,0,0,0.02]`，使两端载荷小幅非零。训练和采样共用同一因子 F 及 `R=F Fᵀ`；逐窗目标为 `[log det R + z*ᵀR⁻¹z* − z*ᵀz*]/(2N)`，真实同步终点经原 motion_frame 与冻结四层 Flow 的 `inverse=True` 得到 z*。未来只用于训练目标和离线计分，ID 只用于对齐与随机键。

每窗一次产生 256 个完整联合场景，以所有有效行人端点距离的均值定义场景距离，贪心选 20 个实际样本；首个最小化总距离，其后最大化总最近距离下降，同分取较小原抽样编号。端点不经过逐人 KMeans、Hungarian 或后置选择。20 组联合终点统一调用冻结修正头一次，再以 eta=0 进入一次 20 步 DDIM。个人噪声、无向边噪声、桥噪声与置乱使用独立随机流；桥噪声绑定 scene、agent、原始联合抽样编号和 seed2035，置乱时保持端点/噪声绑定。

模型、似然、Flow 和桥使用 FP32；离散代表选择的距离累加使用 CPU float64，该数值方式已在运行配置中固定。AdamW lr=1e-4、weight decay=1e-4、梯度裁剪 5、逻辑批 16 窗、5 轮 warmup、100 轮余弦调度、minimum30/patience15/max100。优化器只含依赖网络，窗口等权，不按行人数重新加权损失。

从独立工作区执行的正式命令如下；同一命令在可恢复中断后读取本次 last，不建立第二次训练。

```bash
env CUBLAS_WORKSPACE_CONFIG=:4096:8 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 ../.conda/rsjg/bin/python -u -m joint_flow_dependency.run --wait-gpu
```
