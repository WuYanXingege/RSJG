## 固定配置与复现

同一固定训练种子、AdamW 分组和 16 窗逻辑批次。依赖网络学习率 1e−4，原修正头最后一层学习率 2e−5，共训练 8 轮；每个逻辑批次按总有效人次归约边缘项，按总窗口数归约联合项、退化惩罚和 ΔNLL。教师与学生共用原始个人及共享边噪声，各自按原生 medoid 选择 K=20。

评价使用 seed=2035 的历史 B 全精度结果。全体 ΔminFDE≤−0.020 m 且 ΔJFDE<0 才解码完整轨迹。正式 minFDE 按人次加权。L 是各窗逐人最佳终点距离的均值再按窗等权，G=JFDE−L，按窗等权。两折分别判定。

所有已完成轮次保留可恢复权重。第 8 轮固定用于评价，中间轮次未做探索集验证，也没有用于排名的验证分数。

`CUBLAS_WORKSPACE_CONFIG=:4096:8 OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 CUDA_VISIBLE_DEVICES=0 python -m k20_dual_finetune.run`
