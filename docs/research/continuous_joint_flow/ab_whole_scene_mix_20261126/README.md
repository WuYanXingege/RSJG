# 五折 A/B 整场轨迹组合探索性回放

**五折平均未同时改善四项。** 新方案相对 B 的全体五折等权差值为 JADE +0.624 cm、JFDE +1.235 cm、minADE -1.226 cm、minFDE -3.677 cm。**结束本版固定组合方案，保留原有模型。**

方案在查看历史测试结果后确定，属于探索性回放。五个固定推理种子描述同一权重下的推理波动。每个种子独立保留 20 个整场预测，五折使用同一个规则。

已评分 3348 窗、16740 个窗种子配对。2535 个单人窗种子配对的四项指标逐项精确等于 A。

## 固定组合与运行成本

单人窗直接输出 A。多人窗根据预测轨迹之间的距离，从 B 的 20 个整场中贪心删 4 个，再从 A 贪心补入 4 个整场。距离为 12 帧平均欧氏距离与末帧欧氏距离各占一半。两个阶段均以原始槽位解决同值。整个选择仅使用预测、有效掩码和成员顺序，封存全体槽位及源预测哈希后才统一评分。

输入使用五折正式冻结 A/B 原始轨迹。ZARA2 的历史 A 基线身份沿用其原归档。同窗种子的原 A/B 指标使用原生评分器复核，训练更新为 0。

离线组合用时 44.669 秒（含源轨迹读取及哈希核验），其中选择器 CPU 累计 27.429 秒。评分用时 71.217 秒，总用时 117.343 秒。

实际补推 0 个窗种子配对，新增 0 路模型前向。在线多人窗仍需先运行 A 和 B 的两路整场轨迹预测，再选择用于输出的 20 个整场。输出预算为 K=20，推理开销需计入两路采样和解码。单人窗只需 A。

冻结资产就位后可在训练主机上用以下命令复现。

`OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m ab_whole_scene_mix.run`
