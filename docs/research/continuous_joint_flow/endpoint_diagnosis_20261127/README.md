HOTEL 的 S0 为 S24，UNIV 的 S0 为 S16。两折分别与已封存 R12 配对。首页使用测试集诊断，开发集复核与五种子路径汇总列在后文。

## HOTEL

1. **误差集中在哪些窗**　301 个多人测试窗贡献全折 84.0% 的 S0 JFDE 总和。S0 误差最高的 45 窗贡献 29.7%。

2. **最早在哪层看到**　这批高误差窗的 raw J / L / G 已达 1.217 / 0.634 / 0.584 m。候选覆盖不足和槽位共用代价均已出现。

## UNIV

## 唯一后续验证

**优先验证联合槽位构造。** UNIV 密集窗的原生 G 较大，且固定端点后已有可测的槽位松弛空间。HOTEL 高误差窗同时有覆盖不足，用两折独立结果衡量迁移效果。在原开发集保持每人 K20 终点集合固定，只用观测和候选终点重新构造共享槽位，以逐人 minFDE 恒等和联合 JFDE 的配对变化验收。先做端点评分即可检验这项改动。
