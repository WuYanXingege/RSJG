# ZARA2 固定模型五 seed 测试结果

固定 B 在本次测试的五 seed 均值上仍降低全体 JADE、全体 JFDE 和 N≥9 JFDE。

比较对象均为同一组 **998 个测试窗口**。其中 N≥9 为 **214 窗、2197 人次**；全体为 **5910 人次**。B 固定使用开发集选出的 epoch35，测试过程中没有训练、模型选择、阈值选择或额外 seed。下述差值一律为同一 seed 下 B−A，负值表示 B 较低。

全体 JADE 下降 0.0617312121089 m；全体 JFDE 下降 0.140312728067 m；N≥9 JFDE 下降 0.202348238397 m。全体边缘 minFDE 上升 6.57859433521 cm；N≥9边缘 minFDE 上升 8.52976102118 cm。这些结论只比较同测试集、同 seed 的 A/B，**不套用开发集三项门槛**，也不作为其他折的结果。

## 冻结身份与先预测后评分

A 为旧 v2 coordinate epoch5，checkpoint SHA256 `9281673fda5c439bdd463b0bfc9af1a65a3a0fea30941ad3c956cbb617943317`。B 固定为 epoch35，checkpoint SHA256 `ea13cd7fd99a02c44c3c9af9a14a0cc9b5166b629e5c338694cca97f1c8c502a`，开发集归档提交为 `d4fbe6d8e3b142645b9e801116aac308fcb19c9d`。Provider density19、修正头 epoch9、原编码器、原配对头、六层桥与依赖网络均冻结为 eval；本次没有优化步骤，测试前后模型状态哈希完全相同。B 采用已冻结的连续联合采样、256→20 整组压缩、一次有界修正及一次 20 步 DDIM；A 使用旧 H0 原生入口。SSEC 保持原监督器记录的暂停状态，既有训练队列及原实验任务状态均未改变。

正式测试之前，seed2035 在全部 590 个开发窗口（其中 127 窗 N≥9）复现 A/B 的归档原生指标，结果完全一致；见 [开发集复现](DEV_REPLAY.json)。该复现只检查冻结入口，没有重新选模。

全部 **4,990 个预测文件**先封存为 float32 的 A/B 两套 `[20,N,12,2]` 数组，文件中不含真值。评分入口先核对完整清单、固定配置身份、每个文件的 SHA256、形状、类型与有限性；完成全部核对后，才构造 `FormalData(..., 'scoring')` 并读取测试未来。每个窗口只读取一次未来，随后独立评分五个 seed。封存时间 `1795354553.904598`、全部核验完成时间 `1795354556.5819037`、首次未来读取时间 `1795354556.7087138`，均为 Unix 秒，顺序已核验。

原始封存清单 SHA256 为 `71f8fb531304063ce7d381df4651283c015f5bc6e90d2ed032b929ee21da2b95`。公开 [匿名预测封存清单](PREDICTIONS_FROZEN_PUBLIC.json) 保留每个匿名窗口/seed 的预测文件哈希；原始成员索引、预测文件、权重、候选库和轨迹保留在训练主机。
