# 直接生成 K20 的五折轨迹预测

本实验由历史测试结果启发，属于五折五种子探索性对照。五个种子衡量固定权重的推理波动。

**五折等权四项都低于 B。** 可作为独立数据验证的替代候选。

正式评分覆盖 3348 窗、16740 个窗种子配对。五折权重先冻结，全部预测封存后统一读真值。每个种子单独使用 K20，联合指标按窗等权，边缘指标按有效行人人次加权。先对同种子各折等权，再求五种子均值与样本标准差。

## 训练、选模与推理

学生使用 20 个查询直接生成 20 个整场场景。个人与整场教师匹配只参与训练。Flow、修正头、编码器和桥均冻结。第 13–24 轮每个 16 窗逻辑批抽两窗运行可导的完整 DDIM，用入选概率修正 ADE 项。验证只发生在第 12、16、20、24 轮，按最大相对 B 比值、平均比值、较早轮次依次选模。
