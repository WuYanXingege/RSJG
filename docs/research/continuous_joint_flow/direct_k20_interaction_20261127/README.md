联合 JADE、JFDE、L 和 G 按窗等权，边缘 minADE、minFDE 按有效行人人次加权。L 是窗内逐人的最小终点误差均值，G 为 JFDE 减去 L。配对差统一为 R12−S0，负值表示误差降低。

两折均使用原生 20 步 DDIM 和每个种子独立的 K20，配对预测共享窗口、行人顺序及逐槽噪声。
