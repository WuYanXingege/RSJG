============================================================
二、优化目标
============================================================

当前瓶颈：

- synchronized scene-window 路径的 DataLoader 外层仍为 batch_size=1；
- 一个 item = 一个真实同步 scene-window；
- 每个 window 的行人数 N 可变；
- coupling_grad_accum_steps 只能扩大 effective optimization batch，不能真正提高 GPU 并行度；
- upstream GDTS 已冻结，但训练时仍重复执行昂贵的 diffusion tree sampling；
- 不同 scene 的地图尺寸、homography、scene object 和 N 不同，
  因此不能直接把 DataLoader(batch_size=1) 改成 4。

本次只做工程加速，不改变 V4 方法本身。

核心方案：

    Frozen upstream multi-seed trajectory bank cache
        +
    variable-N multi-scene packing
        +
    sparse graph index offset
        +
    strictly scene-balanced loss reduction

============================================================
四、Frozen Upstream Trajectory Bank Cache
============================================================

当前 V4 中 upstream GDTS 已冻结，因此训练 coupler 时每个 epoch 重复执行完整 diffusion sampling 不产生新的梯度。

对每个 synchronized window w，预先生成多个随机 seed 的 K=20 trajectory banks：

    B_w^(q) = {Y_i^(q,k)}

其中：

    q = 1,...,S_seed
    k = 1,...,K
    K = 20

建议默认：

    num_cached_seeds_per_window = 4

每个 seed 必须始终独立保持 K=20。

禁止：

    seed0 的 20 条
    +
    seed1 的 20 条
    =
    K=40

训练时：
- 每个 window 每次只随机选择一个 q；
- 同一个 forward 内始终只有 K=20。

Validation / Test：
- 每个 seed 独立做 K=20 evaluation；
- 最后对 seed 指标求 mean/std；
- 不得合并成 K=80。

        [N,T_pred,2]

    raw_trajectory_banks

不要缓存 trainable V4 模块的输出，例如：
- trajectory feature；
- pair score；
- pair relation posterior；
- pair gate；
- Sinkhorn matrix。

这些必须训练时在线计算。

============================================================
九、Multi-Scene Packing
============================================================

完成 trajectory cache 后，coupling 阶段只处理统一的 world-coordinate tensors：

    obs_world
        [N,T_obs,2]

    gt_future
        [N,T_pred,2]

    raw_future
        [N,K,T_pred,2]

不同 scenes 可以沿 agent 维 concatenate。

packed batch：

    obs_world
        [N_total,T_obs,2]

    gt_future
        [N_total,T_pred,2]

    raw_future
        [N_total,K,T_pred,2]

    scene_index
        [N_total]

    scene_ptr
        [num_scenes+1]

其中：

    N_total = Σ_s N_s

同时保留：

    scene_names
    frame_ids
    agent_ids
    window_ids
    selected_seed_indices

============================================================
十、Dynamic Scene Packing
============================================================

不要简单固定：

    batch_size = 4 scenes

因为不同窗口 N 和 E 差异较大。

新增参数：

    --max_agents_per_pack 32
    --max_edges_per_pack 256
    --max_scenes_per_pack 8

以 max_agents_per_pack 和 max_edges_per_pack 为主要容量限制。

packing 不能拆分一个 synchronized window。

伪代码：

function build_scene_packs(windows):

    shuffle(windows)

    packs = []
    current = []
    N_sum = 0
    E_sum = 0

    for w in windows:

        N_w = w.num_agents
        E_w = estimate_or_cached_edge_count(w)

        overflow =
            len(current) >= max_scenes_per_pack
            or N_sum + N_w > max_agents_per_pack
            or E_sum + E_w > max_edges_per_pack

        if overflow and current is not empty:
            emit current
            current = []
            N_sum = 0
            E_sum = 0

        add w to current
        N_sum += N_w
        E_sum += E_w

    emit remaining current

============================================================
十一、Graph Packing
============================================================

每个 scene 独立构图：

    edge_index_s [2,E_s]
    edge_feat_s
    edge_weight_s

然后按 agent offset：

    offset = scene_ptr[s]

    edge_index_s += offset

最后：

    edge_index = cat(edge_index_s, dim=1)
    edge_feat = cat(edge_feat_s, dim=0)
    edge_weight = cat(edge_weight_s, dim=0)

必须 assert：

    scene_index[edge_index[0]]
    ==
    scene_index[edge_index[1]]

若出现跨 scene edge：
    立即抛错。

============================================================
十二、Packed Forward
============================================================

pack 后：

    raw_future [N_total,K,T_pred,2]

可以一次性输入：
- trajectory encoder；
- pair-conditioned relation；
- trajectory pair energy；
- pair-specific gate；
- multiway synchronizer。

只对 E_total 条 sparse edges 构造 pair tensors。

禁止构造：

    [N_total,N_total,K,K,...]

只允许：

    [E_total,K,K,...]

============================================================
十三、最关键：保持 Scene-Balanced Loss
============================================================

旧 single-scene 训练时：

    一个 step = 一个 scene-window

如果 packed 后直接：

    mean over N_total agents

会让大 N scene 权重更高。

如果直接：

    mean over E_total edges

会让拥挤 scene 权重更高。

这会改变训练目标。

默认必须：

    scene_balanced_loss = True

对于每个 scene s 独立计算：

    L_alignment_s
    L_pair_score_s
    L_pair_assignment_s
    L_no_harm_s
    L_entropy_s
    L_relation_prior_s

然后：

    L_total
    =
    mean_s L_total_s

pair loss：
先：

    L_pair_s
    =
    mean_{e in scene s} L_e

再：

    mean over scenes

不能直接：

    mean over all packed edges

============================================================
十四、Loss Equivalence Test
============================================================

构造两个 scenes A/B。

分别单独计算：

    L_A
    L_B

期望：

    L_expected
    =
    (L_A + L_B)/2

packed 后：

    L_pack

要求：

    abs(L_pack-L_expected)
    < tolerance

逐项验证：

    L_alignment
    L_pair_score
    L_pair_assignment
    L_no_harm
    L_perm_entropy
    L_relation_prior
    L_gate_reg

============================================================
十五、Packed vs Single Deterministic Equivalence
============================================================

取 scene A、B。

固定：
- cached bank；
- model eval / deterministic mode；
- RNG；

分别运行：

    A single
    B single

和：

    pack(A,B)

比较：
- trajectory features；
- relation posterior；
- pair energy；
- pair gate；
- Sinkhorn P；
- Hungarian permutation；
- component membership；

要求：
pack 中 A/B 的结果分别与 single 基本一致。

十六、Multiway Synchronizer Scene Isolation
============================================================

packed 后必须保证：

- connected component search 不跨 scene；
- anchor/gauge 不跨 scene；
- Sinkhorn synchronization 不跨 scene；
- keep confidence 不跨 scene；

============================================================
十七、显存约束
============================================================

pair tensor 主要复杂度：

    O(E_total K^2 M)

因此 pack 不应只按 N 限制。

必须同时支持：

    max_edges_per_pack

启动训练时打印：

    num_scenes
    N_total
    E_total
    K
    M
    estimated_pair_elements
    estimated_pair_memory_mb

若 pack 预计超过设置：
    自动拆包。

============================================================
十八、Gradient Accumulation
============================================================

multi-scene packing 与 grad accumulation 分开。

例如：

    max_agents_per_pack=32
    coupling_grad_accum_steps=2

表示：
- 一个 forward 已经包含多个 scenes；
- 两个 packed forwards 后再 optimizer.step。

确保：

    loss = loss / grad_accum_steps

再 backward。
