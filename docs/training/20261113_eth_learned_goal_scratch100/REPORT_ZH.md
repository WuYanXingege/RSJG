# ETH：从零学习终点分布的8层EBJD，100轮试验

这是新的研究模型，不是旧固定候选模型的执行优化或续训。
本轮目标是检验独立终点学习能否解除外部候选对minFDE的限制；尚不能宣称精度改善。

## 实际方法

共享MSCE（历史/社交＋地图）→ 可训练终点分布 → 可学习联合配对 → 8层条件联合桥。
192维、4头、FFN768；4个粗预测block＋4个精修block；FULL/CTF/Raw。
所有预测网络参数随机初始化，包含地图U-Net；不加载Goal-pretrain、GDTS或旧EBJD权重。
GDTS原有结果JSON只用于固定比较与原selector，不进入梯度或初始化。
既有地图资产仍为共同数据输入，不宣称地图资产制备过程也不存在外部先验。

终点头读取social_h与地图memory的空间平均特征，预测20个等权二维对角高斯分量。
坐标是相对恒速终点的残差，使用仅从训练折拟合的goal RMS归一化。
标准差采用平滑有界参数化，范围[0.05,4.0]（归一化单位），初始化约0.75。
均值随机小尺度初始化，避免完全相同分量的对称性。
训练与推理均每分量重参数抽样一个候选，共20个；这是分层抽样，不是TTST，也不是20次IID混合分布抽样。
没有GT参与候选生成或筛选。

目标为归一化坐标下的等权高斯混合负对数似然（权重1）＋联合配对softmin（权重1）
＋原条件桥v去噪及辅助损失（coarse0.25、geometry0.05、map0.10）。
配对损失经候选坐标重参数路径训练终点头，经原Hungarian/Sinkhorn直通替代梯度训练配对头。
单人场景使用已有identity替代梯度：没有虚假的配对决策，但终点坐标仍得到梯度。
桥仍以GT终点为条件做去噪监督，不把错误预测终点强行固定后再要求精确重建另一个GT终点。
桥损失共享编码器梯度，但不声称通过20步采样直接训练终点头。

同一checkpoint及同一候选集合下，G/H仍保持逐人minFDE不变；
不同epoch的终点分布可变化，因此minFDE不再被外部bank锁死。
这不保证候选覆盖一定改善，也不把现有混合密度头本身宣称为独创算法。

## 固定训练合同

- ETH，training seed3101，从epoch1开始完整训练100轮，禁用性能早停。
- 每logical microbatch4场景，累积4；保留全部行人，物理场景逐个执行，尾批使用实际累积数归一化。
- AdamW，所有随机初始化模块含地图U-Net基础LR=1e-4；不沿用预训练U-Net的1e-5微调LR。
- 前5轮线性warmup，后95轮余弦衰减至基础LR的0.1；不误用旧30轮日程。
- BF16网络＋FP32损失/几何/优化器；终点概率和采样FP32。
- rollout与paired actual-step projection全程OFF。
- legacy_cpu_rigid输入、4 workers；小组≤16槽位的去噪器保留图，大组checkpoint回退，地图U-Net checkpoint不变。
- 每epoch验证一次，20候选/20DDIM步，selection seed2035。
- 选模仍为best_eligible（四项不高于matched-GDTS且JADE最优），没有则best_jade。
- 保存完整last、best_jade、如有best_eligible及epoch100 final；不将final直接当best。
- 结束后固定所选checkpoint评测2035–2039，一个训练seed、五推理seed。
- 训练4110场景/36906次行人出现；验证253/364，平均1.438735人/窗口。验证/测试成员镜像，不是独立测试集。

配置在`configs/RESOLVED.json`和`configs/CONTRACT.json`；完整身份、源码和配置哈希绑定RUN_MANIFEST。

## 验证与边界

针对性单测覆盖：混合NLL与独立概率实现相符、候选重参数梯度、配对双射、padding、
行人重排、平移、禁止外部权重加载、地图/终点/配对/去噪梯度、完整优化器/RNG恢复与100轮LR。
真实数据启动检查使用临时模型执行完整累积更新，以及3场景的20world/20步推理。
正式训练另起进程、重新设置seed3101，不继承任何检查权重或RNG。
机器可读检查收据单独保存；小样本启动检查不是最终精度评测或速度认证。

新旧方法的终点生成和初始化均有实质变化；旧固定bank结果不能记到本方法名下。
无预训练可能增加收敛难度，100轮结果未知；本轮不扫描组件数、方差范围、loss权重或seed。

实际启动预检：11项测试通过；真实两次完整累积更新覆盖32场景、318次行人出现，最大42人；
终点、配对、地图和桥梯度均有限且非零；1/2/2人三个真实验证窗口20/20推理通过。
固定输入与噪声的终点候选更新后最大变化0.015762米，证明候选不是固定bank。
峰值allocated约1624.34MiB，仅为短预检范围；含一次配置类型失败及补充检查的GPU开发墙钟34.38秒。
这些检查不用于宣称预测精度或完整训练速度。
